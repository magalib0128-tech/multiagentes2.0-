# Escenario Multiagente | Margaret Hamilton y Profe Nexo

Set 3D con cámaras de cine donde conversan dos agentes de voz de ElevenLabs (Proyecto DIA, Didáctica con IA).
Dos modos: **En vivo** (charlás por micrófono y les pasás la palabra nombrándolos o tocando su nombre) y **Guion** (actúan un guion con las voces de ElevenLabs o la del dispositivo; la página graba un video 1920×1080).

## Publicar en GitHub Pages
1. Creá un repositorio público nuevo (por ejemplo `escenario-multiagente`).
2. Add file > Upload files: subí `index.html` y `README.md` > Commit changes.
3. Settings > Pages > Deploy from a branch > `main` / `/ (root)` > Save.
4. Abrí `https://TU_USUARIO.github.io/escenario-multiagente/`.

## Importante
- En vivo y las voces de ElevenLabs solo andan con la página publicada (https), no abriendo el archivo con doble clic.
- Cada turno gasta créditos de ElevenLabs. La clave de API es tuya (ElevenLabs > Developers > API Keys): no la compartas.
- En ElevenLabs, pestaña Security de cada agente: autenticación desactivada; si usás lista de dominios, agregá `TU_USUARIO.github.io`.
